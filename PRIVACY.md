# Tucket Grab privacy policy

Tucket Grab collects nothing about you.

- It reads a web page only when you open it on that page.
- Colours, fonts, SVGs and screenshots stay in your browser until you copy, send or download them.
- Screenshots are kept on your computer, inside the extension's own storage, so the result tab can show them. They are deleted after a day or once five newer captures exist.
- It stores a few things on your computer only: your colour format, colours you picked with the eyedropper, where you left the panel on each site, and cached font lookups (below).
- **Font lookups.** When the Font tab shows a web font the page doesn't name a source for, Tucket Grab asks [Fontsource](https://fontsource.org) whether that font is free to download. Only the font's family name is sent (for example "Inter"), never the page address or anything about you. Answers are cached on your computer for a month. This is the only request Tucket Grab makes on its own.
- **Tucket for Mac.** If Tucket 1.3.8 or newer is installed, Tucket Grab hands captures straight to it on your Mac through the browser's native messaging. Nothing goes over the network.
- When it reads an SVG file, the request goes to the site you're on, the same way the page already loaded it.
- No analytics, no tracking, no accounts, no remote code.
- Links to trytucket.com carry a `utm_source` tag, so the website can count visits that came from the extension. Links to font stores open only when you click them.
